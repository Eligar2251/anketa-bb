# Проверки единого редактора

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install --with-deps chromium
pnpm test:e2e
pnpm build
```

Тесты запускают сборку и отдельный production-сервер на порту 3100. Не запускайте их
одновременно с другим Next.js-процессом в той же папке `.next`.
Для установленного вручную Chromium можно задать
`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

Проверяются обычная анкета и её двойной режим, перенаправление старых ссылок `/v2`
в `/editor`, галерея с одной кнопкой «Анкета», отсутствие подписей «герб» и «свиток»,
сохранение черновика, перенос через localStorage, добавление поля с фото,
загрузка/подпись/масштаб/удаление, размеры эритрогенов и создание новой анкеты.
Квадратная фото-ячейка проверяется отдельно: равенство сторон, панель масштаба
(100% после загрузки, кнопки «−/+» и «Вписать»), изменение размера ячейки за угол
и сохранение этого размера после перезагрузки страницы.
Также проверяются: центрирование фото-ячейки в поле и подъём фото на место пустой
строки, когда подписи нет (подпись возвращается кнопкой «＋ Подпись» на панели);
строка уровня эритрогенов как одна система — буква, число и пояснение на общей
горизонтальной оси в обеих колонках, название сразу после числа и единиц,
прямые цифры и ширина поля по содержимому; размеры выводятся из одной настройки, разделителя перед блоком
нет; экспорт PNG — все четыре уголка рамки портрета попадают в файл (пиксели углов
читаются из скачанного файла прямо в браузере).
Запросы Supabase и Cloudinary подменяются в браузере: тесты не меняют реальные
анкеты и не подтверждают доступность production-сервисов или публикацию сайта.
