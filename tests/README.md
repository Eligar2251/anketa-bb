# Проверки единого редактора

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install --with-deps chromium
pnpm test:e2e
pnpm build
```

Тесты запускают сборку и отдельный production-сервер на порту 3100. Не запускайте их
одновременно с другим Next.js-процессом в той же папке `.next`.
Для установленного вручную Chromium можно задать
`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

Проверяются перенаправление `/v2` (включая `?id`), сохранение черновика,
перенос через localStorage, загрузка/подпись/масштаб/удаление фото,
восстановление двойной анкеты, размеры эритрогенов и создание новой анкеты.
Запросы Supabase и Cloudinary подменяются в браузере: тесты не меняют реальные
анкеты и не подтверждают доступность production-сервисов или публикацию сайта.
